# Using development-skills

For development work, read the [development loop](references/shared/development-loop.md).
Read the [engineering contract](references/shared/engineering.md) before design or code changes, and apply `rethink` to each design.
Skip this router for a bounded subagent task.
Resume an active plan at its recorded step. Otherwise select the path that fits the task.
Read [full-path.md](references/shared/full-path.md) only for work that needs a lasting decision record or designed proof.
The loop owns authorization; use `brainstorming` only for material open decisions.
For unavailable Claude tool names, read [tool names](references/tool-names.md).
